Tantrum's Battlegrounds Toolkit - Hearthstone Deck Tracker plugin

The release page also has an installer, TantrumsBattlegroundsToolkit-Setup-<version>.exe,
which does the steps below for you. This zip is the manual way.

1. Extract all the files.
2. Start install.bat (from any folder - location does not matter).
3. Start Hearthstone Deck Tracker. On a first install the plugin is switched on for you.
   If it is not in HDT's Plugins menu, switch it on under Options > Tracker > Plugins.

If Windows Defender flags the plugin, that is a false positive. Please add the file to
the ignore list and contact .tantrum. on Discord to help with resolving the issue.
