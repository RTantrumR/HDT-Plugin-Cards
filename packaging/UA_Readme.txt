HSBG Card Lookup - плагін для Hearthstone Deck Tracker
======================================================

ВСТАНОВЛЕННЯ (просто - рекомендовано)
1. Клік правою по архіву > Видобути все (розпакуйте весь архів у теку).
2. Двічі клікніть install.bat. Він закриє HDT, якщо відкритий, і скопіює плагін куди треба.
3. Запустіть HDT. Якщо буде запит — увімкніть плагін у розділі Options > Plugins.
4. Натисніть F3 (у грі чи будь-де), щоб відкрити пошук карт.

ВСТАНОВЛЕННЯ (вручну - якщо не хочете запускати .bat)
1. Повністю закрийте Hearthstone Deck Tracker (зокрема вийдіть із нього в системному треї).
2. Скопіюйте теку "HsbgCardLookup" з цього архіву до теки плагінів HDT:
      %APPDATA%\HearthstoneDeckTracker\Plugins\
   (Порада: вставте цей шлях у рядок адреси Провідника й натисніть Enter.)
   У результаті має бути:
      ...\HearthstoneDeckTracker\Plugins\HsbgCardLookup\HsbgCardLookup.dll
3. Запустіть HDT, увімкніть у Options > Plugins за потреби, натисніть F3.

ПЕРШИЙ ЗАПУСК
- Під час першого запуску плагін завантажує зображення карт у фоні (~200 МБ, одноразово).
  Доки триває завантаження, зображення з'являються поступово; після цього вони відкриваються миттєво.
- Дані карт і зображення оновлюються автоматично з hsbg.cards, коли вони змінюються.

КЕРУВАННЯ
- F3            відкрити / закрити вікно
- (текст)       пошук; Tab перемикає розумний пошук; Esc закриває
- F2            показати золоту версію вибраного міньйона
- клік по арту  відкрити цю карту на hsbg.cards

Потрібен .NET Framework 4.7.2 (вже встановлений, якщо працює HDT).
