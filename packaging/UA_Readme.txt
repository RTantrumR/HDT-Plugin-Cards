Tantrum's Battlegrounds Toolkit - плагін для Hearthstone Deck Tracker

1. Розпакуйте всі файли.
2. Запустіть install.bat (з будь-якої теки - розташування не має значення).
3. Запустіть Hearthstone Deck Tracker. Під час першого встановлення плагін вмикається сам.
   Якщо його немає в меню Plugins у HDT, увімкніть його в Options > Tracker > Plugins.

Якщо Windows Defender позначає плагін як загрозу - це хибне спрацювання. Додайте файл
до списку винятків і напишіть .tantrum. у Discord, щоб допомогти вирішити проблему.
